# Git Cheat Sheet

- `git config --global user.name "Your Name"` - sets your name for all your commits.
- `git config --global user.email "you@example.com"` - sets your email for all your commits.
- `git config --global --list` - shows your saved Git settings.
- `git clone <repo-url>` - downloads a copy of a repo from GitHub to your computer.
- `cd <folder>` - moves you into a folder.
- `git checkout -b <branch-name>` - makes a new branch and switches to it.
- `git status` - shows which files changed and which are ready to commit.
- `git add <file>` - marks a file as ready to commit.
- `git commit -m "message"` - saves your marked changes with a short message.
- `git push -u origin <branch-name>` - sends your branch to GitHub.
- `git checkout main` - switches back to the main branch.
- `git pull` - gets the newest changes from GitHub.
- `git log --oneline` - shows the list of commits, one line each.
